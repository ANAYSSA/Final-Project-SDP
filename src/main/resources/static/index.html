THE IDEAS BEHIND THE EXPERIENCE

Six patterns.
One shared table.

A Restaurant Ordering System built with Java, Spring Boot and a small, purposeful web interface. Each design pattern has a real job in the journey from menu to order.

01 / CREATIONAL

Factory Method

Specialised creators produce pizza, pasta and drink objects through a shared meal interface.

Anuar · Menu creation
02 / CREATIONAL

Builder

Assembles a valid, immutable order step by step with the customer, dishes and service details.

Anuar · Order assembly
03 / BEHAVIORAL

Strategy

Changes the discount calculation at checkout: standard, student, takeaway or family pricing.

Akmaral · Pricing
04 / STRUCTURAL

Bridge

Separates the type of receipt from its format. Customer and kitchen documents both support text, HTML and JSON.

Akmaral · Receipts
05 / BEHAVIORAL

Observer

Notifies the customer, kitchen and operations view when an order changes status, without coupling the order to its listeners.

Mukhammad · Notifications
06 / STRUCTURAL

Decorator

Wraps a meal in optional toppings, adding their descriptions and prices without changing the original dish.

Mukhammad · Extras
